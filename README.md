# 学習プリントメーカー

公開 URL: **https://yorozu-craft.com/gakushu-print/**

ひらがな・カタカナ・漢字・計算・百ます・時計・迷路の学習プリントを無料で作成。登録不要、毎回ちがう問題、答えつき。A4 で印刷・PDF 保存。
yorozu-craft のツールの1つです（共通ルールは [youheioonuki.github.io の README](https://github.com/YouheiOonuki/youheioonuki.github.io) を参照）。企画は yorozu-plans の `docs/10_学習プリント.md`。

## 機能

| 種類 | 選べること | 答え | 自分で入れる |
|---|---|---|---|
| たし算・ひき算 | 1けた〜3けた・10いくつと1けた、くり上がり／くり下がりの なし・あり・まぜる、よこ／筆算、1 枚 10〜30 問 | あり | 入れたい問題（`7+8` など 1 行 1 問。まぜる／それだけ） |
| 九九 | 段（複数）、順・逆・ばらばら | あり | 入れたい問題（`6×7`） |
| 百ます計算 | たし算・ひき算・かけ算、10×10／5×5、左利き用、正解数とタイムの欄 | あり | — |
| 時計の読み方 | 何時／何時半／5 分／1 分、読む・針をかく、分の補助数字 | あり | 入れたい時刻（`7:30`、`7時半`） |
| ひらがな・カタカナ | 行（清音・濁音・半濁音・小さい字）、ますの大きさ 3 段階 | — | なぞる言葉（名前など。その文字の種類だけ残し、ほかは外して知らせる） |
| 漢字練習 | 1〜6 年生、表の順（何番目から）・ばらばら | — | 字をえらぶ（一覧をタップ／はりつけ。選んだ学年までの字だけ） |
| 迷路 | かんたん 7×9・ふつう 13×16・むずかしい 22×28。必ず解け、道はひとつ | あり（道を線で） | — |

共通: 名前（なまえ欄にうすい字で入る）・日付欄・正解数の欄の有無、答えのページ（問題だけ／問題と答え／答えだけ）、1〜10 枚、印刷物のクレジット（既定で表示・外せる。着地ページ `print/`）。

- **同じ問題の再現**: 問題は種（seed）から作る。同じ種と設定なら同じ問題（プリントの下に「もんだい ばんごう」）。共有リンク `#s=`（base64url の JSON: 種類・その種類の設定・共通の設定・種。名前は既定で入れない）で、家族や先生と同じプリントを印刷できる。4,000 文字を超えるときはファイルでの受け渡しを案内
- **保存**: `gakushu-print_settings`（いまの設定）、`gakushu-print_presets`（よく使う設定。最大 30 件・種は持たない＝呼び出すたびに新しい問題）
- **バックアップ**（D31）: `{ tool: 'gakushu-print', version: 1, exportedAt, data: { settings, presets } }`、`gakushu-print-backup-YYYYMMDD.json`
- **印刷**: 見本（`#sheets`）がそのまま印刷される（`@media print` でほかを隠す。`beforeprint` でも作り直す）ので、Ctrl+P でも白紙にならない。A4 縦・余白 0 の `@page`、1 枚ごとに改ページ。広告（`ins.adsbygoogle` など）は印刷しない
- **なぞり書きの字**: 端末に教科書体（UD デジタル 教科書体・游教科書体・Klee）があれば使い、なければ端末のゴシック体。Web フォントは読まない（サイト README の 9）

## 問題の作り方（仕様）

- 乱数: mulberry32。用途（問題・ページ）ごとに種を混ぜて使う（`calc.js` の `makeRng`）
- たし算のくり上がり＝どこかの位で和が 10 以上（5+5 も「あり」）。ひき算のくり下がり＝どこかの位で上の数字が下より小さい。「なし」「あり」は条件を満たすまで引き直す（テストで全問を確かめる）。1けた−1けたの「くり下がりあり」は作れないので選べない
- 同じページの中で同じ問題を出さない（組み合わせが足りる限り）。足りるときはページをまたいでも出さない
- 百ます: たし算・かけ算は 0〜9（25 ますは 1〜9 から 5 つ）、ひき算は上 10〜19・左 0〜9
- 時計: 分の読み方は 1・3・4・6・8・0 で終わると「ぷん」。組み合わせを一巡するまで同じ時刻を出さない
- 迷路: growing tree 法の完全迷路（通路の数＝マスの数−1、すべてつながる）。むずかしいほど枝分かれが多い。答えの道が短すぎれば作り直す
- なぞり書き: 1 字は「お手本・なぞる×n・空き」の 1 行。言葉は「お手本＋なぞる／なぞる／空き」の 3 行で、ページをまたがせない

## データの出典

- **漢字**: 文部科学省「小学校学習指導要領（平成29年告示）」第2章第1節 国語 別表「学年別漢字配当表」（2020 年度から全面実施、1,026 字）。学年ごとの字の一覧だけを `constants.js` に持つ（読み・例文・筆順は持たない）。告示は著作権の目的とならない（著作権法第13条第1号）。
  - 転記の方法: 文部科学省の PDF は配当表の字がテキストとして取り出せない（字形の画像・アウトライン）ため、Wikipedia「学年別漢字配当表」の各学年の節から字を取り、学年ごとの字数（80・160・200・202・193・191）・合計 1,026・重複なし・2017 年改定で第 4 学年に入った都道府県名の 20 字をテストで確かめた（`tests/data.test.js`）。Wikipedia の文章は使っていない（字の一覧は事実）。
- 五十音の行（あ行〜わ行・濁音・半濁音・小さい字）は `calc.js` に直接書いている。

## 保守

| 時期 | 確認すること | 直す場所 |
|------|------------|---------|
| 学習指導要領の改訂時（次は 2030 年ごろの見込み） | 学年別漢字配当表の変更 | `constants.js`、`tests/data.test.js` の字数、`guide.html` の出典と最終確認日 |

直したら、`guide.html` の「更新履歴」に日付と内容を 1 行足す。

## ファイル

| ファイル | 役割 |
|---------|------|
| `index.html` | ツール本体（設定・見本・印刷・共有・よく使う設定・バックアップ） |
| `guide.html` | 使い方・種類・印刷のコツ・学年の目安・よくある質問（FAQPage）・出典・ご利用上の注意・更新履歴 |
| `print/index.html` | 印刷物のクレジットから来た人の着地ページ（`noindex`、sitemap に載せない） |
| `calc.js` | 問題づくり（乱数・計算・百ます・時計・迷路・なぞり書き・読み取り・ページ分け・共有・正規化・バックアップ）。純粋関数 |
| `sheets.js` | プリント 1 枚ずつの HTML（問題と答え） |
| `constants.js` | 学年別漢字配当表（値・出典・確認日） |
| `main.js` | 画面の制御・保存・共有リンク・印刷 |
| `style.css` | 見た目（和紙風の配色、ダークモード対応）とプリント（mm 単位）・印刷 |
| `404.html` | ツール配下の存在しない URL で出るページ（サイト共通のもの） |
| `favicon.svg` / `apple-touch-icon.png` / `og-image.png` | アイコン / ホーム画面用アイコン / SNS 共有用画像（1200×630） |
| `sitemap.xml` | サイトマップ（`/` と `guide.html`。robots.txt はドメイン直下で管理） |
| `tests/*.test.js` | テスト（`node --test tests/*.test.js`。`.github/workflows/test.yml` で push・PR のたびに自動実行） |
